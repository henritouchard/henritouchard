# PROTOTYPE — favicon et images Open Graph (jetable)

Ticket : « Favicon et images Open Graph des récits » (#23), carte « Charte graphique Henri Touchard » (#19).
Base : logo 7b, encre nuit `#0E1626`, corail `#F0503C` / `#C7362A`, Space Grotesk + IBM Plex.

Ouvrir : `xdg-open prototypes/favicon-og/index.html`
- `?vue=favicon&variant=F1|F2|F3` : tuile complète · tuile renforcée en petit · trait et point en petit. Onglets clair/sombre, zoom au pixel 16 et 32, résultat Google, icônes iOS et Android.
- `?vue=og&variant=A|B|C|D` : bande encre · le trait traverse · triptyque · tuile au centre. **Une seule image pour tout le site** : tuile, « Optimisation opérationnelle », nom, centrés dans le carré que gardent les messageries.
- `&page=accueil|pum|lizee|apropos` : la page partagée ne change que le titre affiché sous l'image.
- Flèches ← → pour changer de variante.

Branche jamais fusionnée.
